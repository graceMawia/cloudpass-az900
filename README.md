# CloudPass — AZ-900 Readiness Coach

CloudPass is a learning and practice application designed to help learners prepare for the Microsoft Azure Fundamentals (AZ-900) certification exam.

## Features

- Practice questions covering cloud concepts, Azure architecture and services, and Azure management and governance.
- Multiple quiz modes, including quick practice, full practice, topic-based practice, and weak-area revision.
- Answer explanations and key learning takeaways.
- Bookmarks for revisiting important questions.
- Progress tracking and quiz history saved in the browser.
- Learning resources and a responsive interface.

## Technology Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React icons

## Run Locally

### Prerequisites

Install Node.js and npm.

### Installation

1. Open a terminal in the project folder.
2. Install the dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open the local URL displayed in the terminal.

### Validation

Check TypeScript:

```bash
npm run lint
```

Create a production build:

```bash
npm run build
```

## Learning Objectives

CloudPass organises its practice content around the three AZ-900 exam skill areas:

1. Describe cloud concepts.
2. Describe Azure architecture and services.
3. Describe Azure management and governance.

The questions are independent practice material and are not official Microsoft exam questions.
